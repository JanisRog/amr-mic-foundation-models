# 09 — Model training and selection

## Shared machinery

1. `cv_precompute_fold_features.py` — per fold, a principal component basis fitted
   on training rows only (four components per target, shared across targets;
   variance 0.99, at most 25 before truncation), cached and reused.
2. `cv_run_architecture.py` — random-forest regression of log2 MIC for every
   configuration in `mtb_rf1000_configs.json` (1,000 configurations, generated by
   `make_rf_config_grid.py`) on all fifteen partitions. Tree predictions are
   aggregated by the median and snapped to the observed MIC ladder; resistance is
   called at the clinical breakpoint. `--top-k` is part of the model.
3. `select_final_config.py` — the one configuration per run: minimise
   cost = 2·vMER + MER, and among configurations within one standard error, take
   the highest balanced one-tier accuracy.

## *M. tuberculosis*

| script | drugs | run directory |
|---|---|---|
| `run_panel_dev.sbatch` | the eight panel drugs | `<model>_both_final1k` |
| `run_rif_dev.sbatch` | rifampicin | `<model>_final1k` |
| `run_inh_redo.sbatch` | isoniazid (24-target candidate list, top 12 per fold) | `<model>_tbrule1k` |

All three naming conventions are listed wherever runs are collected;
`slim_mtb_runs.sh` applies the selection rule to each run, keeps only the selected
configuration's rows, and prints a per-drug arm census.
`submit_mtb_gwasfiltered.sh` runs the development sweep for the reported target set
(`gwasfiltered` + rule bit, run directory `<model>_gwasfiltered_gwfrule1k`), and
`run_panel_holdout_arm.sbatch` scores its selected configuration once on the
held-out isolates, saving per-isolate predictions in the same fit. It takes the
configuration and target count from the development run and refuses to score a
held-out set twice.

For the earlier target set (`both`), `run_panel_holdout.sbatch` and
`run_panel_predictions.sbatch` do the same. `submit_mtb_catalogue_arm.sh` runs the
feature-set comparison: `FEATURES=snp|snp_rule|none` with embeddings, and
`CATALOGUE_ONLY=1` without (through `run_mtb_catalogue_only.sbatch`);
`run_holdout_catalogue.sbatch` scores mutation columns + call on the held-out sets.
Evo 2 was designated primary before evaluation.

## *P. aeruginosa*

`submit_pa_dev.sh` → `run_pa_dev.sbatch`; `run_pa_select.sbatch`;
`submit_pa_holdout.sh` → `run_pa_holdout.sbatch`. `pick_reported_model.py` chooses
each drug's model on **development** cost; `slim_runs.sh` keeps the selected rows.
